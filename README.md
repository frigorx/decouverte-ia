# Découverte de l'IA — LPP Jacques Raynaud / Campus ÉQUATIO

Ressource pédagogique pour l'initiation à l'usage des IA (Parcours Avenir),
classes de Terminale Bac Pro **Métiers de la Sécurité** et **MFER**.
4 modules d'autonomie + 2 modules bonus de perfectionnement (≈ 1h30 chacun),
pour les élèves qui avancent vite. Une seule page, aucune dépendance externe.

Modules bonus (communs aux deux filières) :
- **Module 5 — Parler à l'IA comme un pro** : l'art de la consigne (le « prompt »), avant/après, et fabriquer un vrai outil web.
- **Module 6 — L'IA qui voit… et qui se trompe** : analyser une photo/document, repérer le faux (deepfakes), confidentialité des données, et l'IA dans le métier de demain.

Ressource inerWeb Édu · F. Henninot.

## Contenu du dépôt

- `index.html` — la page (à ouvrir d'un double-clic, ou à publier).
- `assets/logo-lpp.png` — *(optionnel)* logo de l'établissement, affiché en en-tête s'il est présent.
- `assets/logo-equatio.png` — *(optionnel)* logo Campus ÉQUATIO, idem.

> Les deux logos sont facultatifs : s'ils sont absents, l'en-tête reste propre (texte seul).
> Pour les afficher, dépose simplement les deux fichiers `.png` dans un dossier `assets/`.

## Publier sur GitHub Pages (≈ 2 min)

1. Crée un dépôt **public** sur GitHub (ex. `decouverte-ia`).
2. Téléverse `index.html` (bouton **Add file → Upload files**), puis *Commit*.
3. Onglet **Settings → Pages**.
4. **Source : Deploy from a branch**, **Branch : `main`**, dossier **`/ (root)`**, *Save*.
5. Patiente ~1 min : l'URL publique s'affiche en haut de la page Pages.
   Format : `https://<ton-pseudo>.github.io/decouverte-ia/`

C'est cette URL que tu partages aux élèves.

## Accessibilité

Barre « Affichage » en en-tête : taille du texte, **police adaptée**, interligne,
contraste renforcé. Réglages mémorisés d'une séance à l'autre.
Fond toujours clair (pas de mode sombre), navigation clavier, focus visible.
